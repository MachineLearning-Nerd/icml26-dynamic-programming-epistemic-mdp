# Dynamic Programming for Epistemic Uncertainty in MDPs

Clean-room, CPU-only audit of the five scored claims for
[Benyamine et al., 2026](https://arxiv.org/abs/2602.03381), OpenReview
`oUv02QKUxG`.

This is an exact finite-state theorem-instance reproduction, not a model
training or a benchmark subset.  The source paper gives general theorems; the
evidence here validates their stated Bellman mechanisms on complete finite
rectangular uncertainty sets and uses independent matrix solves, exhaustive
policy enumeration, and fail-closed controls.

## Current evidence

Run from this directory:

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
PYTHONPATH=repro .venv/bin/python repro/run_audit.py
PYTHONPATH=repro .venv/bin/python -m pytest -q repro/tests
```

The committed `outputs/summary.json` is regenerated by the first command.  It
currently records:

| Claim | Exact check | Result |
|---|---|---|
| C1 | Theorem 4.1 | 36 full-product finite MDPs; Bellman values agree with independently solved static values to `2.70e-13`. Every stationary policy is exhausted (4, 8, or 16 per instance), plus 4,096 history-dependent prefixes with exact stationary tails. |
| C2 | Proposition 4.2 | All value-iteration greedy-policy bounds have non-positive slack; every policy-iteration step is monotone. |
| C3 | Theorem 4.4 | All 35 quarter-grid four-atom monotone ordered risks are exhausted over six rectangular MDPs: only the two essential extrema pass static Bellman evaluation; resampled expectation matches an independent solve to `9.44e-15`. |
| C4 | Theorem 4.5 | The W1-compatible positive control is resampled expectation; the static expectation witness has Bellman residual `0.08333`, while static spectral controls retain only non-W1-continuous extrema. |
| C5 | Incompatibility discussion after Theorems 4.4–4.5 | `ess inf`, `ess sup`, and expectation satisfy the required independent additivity; CVaR fails by `3.0`. The finite spectral algebra control leaves only min/max/expectation. |

## Negative controls

- A correlated action-row construction is deliberately rejected: history-aware
  policies gain `0.10555`.  That support is **not** state-action product
  support, so it is outside the theorem's assumptions.
- Static expectation is rejected even on a two-state, one-action,
  finite-support analogue of Example 3.8.
- CVaR is rejected by the independent-additivity implication used by the
  paper's classification proof.

## Scope

The project does not pretend that finitely many instances prove universal
theorems.  It independently checks the exact algebra and mechanisms that the
paper relies on, records the theorem assumptions explicitly, and rejects
look-alike cases when those assumptions are removed.  The paper's own complete
general proofs remain the primary source for the universal quantifiers.
